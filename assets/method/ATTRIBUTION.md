# Method-scene geography

`wulin-data.svg` is a static visualisation generated from the existing bounded Overture source GeoJSON under `../tiles/wulin-intime/2026-09-23.1/source/`: building.geojson, segment.geojson and water.geojson. It is not a photograph or measured footfall heatmap. Bounds are WGS84 longitude120.139–120.180, latitude30.251–30.292. Coordinates are linearly mapped to the SVG view box for a diagrammatic preview; no extra building heights, entrances or mall boundaries are inferred.
