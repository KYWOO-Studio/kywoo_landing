# KYWOO Studio 微信小程序

网站 https://kywoolanding.vercel.app/ 的原生小程序版。用小程序自己的组件重做，不嵌入网页。

## 页面

| 标签 | 页面 | 内容 |
|---|---|---|
| 首页 | `pages/index` | 全屏照片轮播（沉浸式顶栏）、关于我们、三个入口、我们的原则、大字、页脚 |
| 服务 | `pages/services` | 数据 / 空间 / 活动三角图解（轻点圆圈，再点回总览，可暂停动效）＋六个主要服务方向卡片（轻点卡片，图解跟着亮起） |
| 案例 | `pages/cases` | 全部 / 当前项目 / 过往经验筛选，十一张案例卡片 |
| 联系 | `pages/contact` | 复制邮箱、复制微信号、对话提纲（可复制）、常见问题 |
| — | `pages/case` | 案例详情：照片、说明、「查看研究汇报」、分享、下一个项目 |
| — | `pages/notes` | 素材与披露 |

每页都可分享给朋友，首页、服务、案例、联系与案例详情也可分享到朋友圈。

## 内容从网站来

`data/content.js` 和 `images/*.jpg` 不要手改，由网站生成：

```sh
python3 scripts/build-mp.py
```

脚本读取 `index.html` 与 `living-loop.js`（图解文字），写出全部文字、链接和压缩过的照片。网站结构改了以致找不到某段内容时，脚本会列出缺什么并停止，不会写出残缺的文件。

几处措辞按小程序改写，写在脚本的 `MP_TEXT` 里：常见问题 06（没有鼠标和 Escape 键）、联系说明（复制而不是打开邮件程序）、外部链接提示、图解操作提示；披露里「3D 模型」改为「三角图解」，去掉 Three.js 一节。

## 小程序与网站的不同

- **外部链接**：小程序里不能直接打开外部网页（需另行配置业务域名）。「查看研究汇报」与项目资料链接会复制网址并提示到浏览器打开。
- **联系**：没有 `mailto:`，改为「复制邮箱」「复制微信号」。
- **图解**：二维 canvas 绘制（三角、连线、流动的点），不用 Three.js；只在看得见且未暂停时运行。
- **字体**：标题用手机自带的宋体/衬线字体，没有时用系统黑体。网站的思源宋体可以在有了自己的 HTTPS 域名后，在 `app.js` 的 `SERIF_FONT_URL` 填上字体地址加载。

## 照片

全部照片都打包在小程序里（主包约 1.3 MB，限制 2 MB），国内网络下不依赖外部网站。网站上从外部加载的照片，原图放在 `images/remote/`（不上传，只供 `build-mp.py` 压缩）：首屏朱家角（Pexels）、朱家角案例两张、JOA 四个项目各一张，2026-11-11 由团队提供。

只有首屏的杭州西湖边街景（Pexels 视频截图）还没有原图，所以小程序首屏用上海上生·新所夜景代替它，「素材与披露」的首屏说明同步改写；把原图存为 `images/remote/hero-westlake.jpg` 再运行脚本，就会恢复成和网站一样。上生·新所详情页另加了一张入口夜景（`assets/projects/columbia-circle-entrance.jpg`，团队提供，摄影署名待补），网站上没有。这两处写在脚本的 `MP_HERO_ADD`、`MP_CASE_PHOTOS` 里。

照片打不开时（例如以后改回外部地址）：首屏跳过，案例卡片显示深绿色项目名方块，详情页去掉那张。

## 在微信开发者工具里打开

1. 安装「微信开发者工具」，导入本文件夹 `miniprogram/`。
2. `project.config.json` 的 `appid` 是 KYWOO 正式小程序「KYWOO商业场所营造」的 AppID（`wxb8359cdf7e7fc6f1`）。AppSecret 用不到，不要放进代码。
3. 正式上线需要：公司主体注册小程序 → 微信认证 → 小程序备案 → 上传代码 → 提交审核 → 发布。类目可选「商务服务 > 设计」之类（以公众平台当前类目为准）。

## 已做的检查

- 官方 wcc / wcsc 编译器编译全部 WXML、WXSS 通过；全部 JS、JSON 语法通过。
- 用 miniprogram-simulate 渲染每一页并模拟点击：首页入口与原则链接跳转（原则 03 打开服务页并选中 04）、图解点选与再点回总览、卡片与图解联动、暂停动效、案例筛选与详情、复制链接提示、下一个项目、复制邮箱/微信号/提纲、常见问题展开。
- 真机效果（字体、图解动画流畅度、分享卡片）需要在开发者工具或手机上确认。
