# KYWOO · Make Space Live

静态落地页，无构建步骤。定位：KYWOO 为既有城市公共空间、商业空间，以及古镇文旅空间提供循证的场所营造策略。我们融合数据、空间与活动的研究和洞察，让冷清的空间重新有人气，成为有活力的城市目的地。

中文版 `index.html` 为主，英文版 `en.html`（线上 `/en`）由脚本生成，见下方「中英文两个版本」。

## 页面结构（2026-11-09 晚起按 Gehl 首页的滚动方式）

页头：「项目」「服务」两项（鼠标移上去或键盘聚焦时展开小节）＋实底「联系我们」＋ EN／中文。页面自上而下：

1. 首屏：全幅大照片轮播＋主标题「让城市中失去人气的空间，重新充满活力！」＋定位句。向下滚动时照片缓慢下移放大、文字淡出（`scroll-fx.js`）。照片在 `#top` 里按 `<img class="cp-slide">` 增减。
2. 关于我们（`#about`，菜单「服务 › 关于我们」）：一句总结，居中，之后直接接「我们做什么」互动图解。
3. 我们做什么（`#approach`，菜单「服务 › 服务内容」）：一张互动图解。中心是数据 × 空间 × 活动 3D 三角，外圈六大方法按关系排布——只连一个方向的方法在该角外侧（05 数据、06 空间、04 活动），连两个方向的在两角之间的边外侧（01 数据·空间、02 数据·活动、03 空间·活动），连线随三角浮动。悬停或点选一个方向，对应的三个方法和连线亮起；点选一个方法，相连的方向亮起；右侧面板显示说明、主要成果，并可跳到相邻的方向或方法。`#strategy-01`…`#strategy-06` 直接打开某个方法。下方「六大方法全文」可展开阅读全部文字（面板内容也取自这里）。没有 WebGL 时三角改为平面绘制，交互不变（`living-loop.js`、`living-loop-scene.js`）。
4. 我们的原则（`#principles`，菜单「服务 › 方法原则」）：全幅效果图（团队提供的葡萄藤凉亭）＋五条原则：01 数据先行／02 我们关注存量空间（含三类空间）／03 从轻小改造试点，持续复盘／04 数据、空间、活动三者联动／05 跨专业协作。
5. 一句大字：「我们关心的，是人为什么来、在哪里停留、如何消费、会不会再来。」随滚动逐字点亮（`scroll-fx.js`）。
6. 案例总览（`#cases`，菜单「项目」）：一行横向卡片，从左到右依次为朱家角、杭州武林银泰（当前项目，卡片两张照片自动轮换：朱家角两张为 Wikimedia Commons 照片，从朱家角研究汇报站 `kywoo-zhujiajiao.vercel.app/media/` 加载；武林银泰两张为 IDA 刊载的改造实景，存于 `assets/projects/wulin-intime-*`）→ 首尔路 7017、上海上生·新所（团队提供照片）→ 佛山宏旺总部、图尔库 Passage、南京文化中心、塔尔图市中心文化中心、洛格罗尼奥 Cierzo 风塔（JOA 建筑项目，资料与图片来自 justopenarch.com，风塔图用 `assets/about/` 的效果图）→ 黄大仙中心、澳门新葡京（项目经验）。可拖动、滑动或用箭头浏览；菜单里的 `#cases-current`、`#cases-past` 把这一行滑到对应分组的第一张，`#project-xxx` 直接打开项目说明（`projects.js`）。照片来源记录在 `assets/projects/credits.json`。
7. 联系我们与常见问题；页脚分栏导航。

各段的标题与卡片进入画面时淡入上移（`.reveal`，可用 `style="--d:.08s"` 设延迟）；系统开启“减少动态效果”时，以上动效全部停止，大字直接完整显示。

手机用点选；原生按钮支持键盘；暂停和系统减少动态关闭持续动画。WebGL不可用时保留平面三角、图片、说明与操作。武林银泰的城市 → 空间 → 决策导览（真实地理地图＋通用楼层）已于 2026-11-09 从页面去掉；地图图砖与数据仍保留在仓库中（见下文），`place-story.js`、`scene.js` 已删除，可从 git 历史找回。

## 中英文两个版本

- 中文 `index.html` 是主版本，所有内容先改这里。
- 英文 `en.html` 不要手改：在 `scripts/i18n_en.py` 里按「中文原句 → 英文」补一行，再运行 `python3 scripts/build-en.py` 生成。有中文没有对应英文时脚本会列出缺的句子并停止，不会写出半中半英的页面。
- 页头右上角 `EN` / `中文` 互相切换，页脚 Contact 栏也有入口；`<head>` 里用 hreflang 标出两个版本。
- 各脚本按 `<html lang>` 显示自己的界面文字（轮播按钮、筛选计数、地图说明、方法网络说明等）。

## 本地预览

```sh
python3 scripts/serve-preview.py
```

打开 http://127.0.0.1:5189/ 。预览服务器支持PMTiles所需的HTTP Range。运行脚本前在仓库根目录。

`app.js` 管理页头、进入动画、披露窗口与复制对话提纲；`living-loop.js`、`living-loop-scene.js` 管理「我们做什么」互动图解；`projects.js` 管理案例总览；`case-photos.js` 管理照片轮播；`scroll-fx.js` 管理滚动效果。Three.js r170 通过 CDN 按需加载。MapLibre 与 PMTiles 运行库及许可仍保留在 spatial/，页面目前未使用。

## 地图数据（页面目前未使用）

独立地图图砖位于assets/tiles/wulin-intime/2026-09-23.1/，由官方Overture GeoParquet生成，不依赖Explorer检查端点。原始有界GeoJSON、清单、ODbL许可及生成脚本一并提供。建筑和高度是来源估计，缺失高度不补算。商场标记为近似公共POI，不是测绘边界、入口或客流。

方法场景的数据背景由同一批GeoJSON生成：`python3 scripts/build-method-preview.py`。署名见assets/method/ATTRIBUTION.md；地图署名见assets/tiles/wulin-intime/2026-09-23.1/ATTRIBUTION.md。
