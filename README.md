# KYWOO · Make Space Live

静态落地页，无构建步骤。定位：KYWOO 为既有城市公共空间、商业空间，以及古镇文旅空间提供循证的场所营造策略。我们融合数据、空间与活动的研究和洞察，让冷清的空间重新有人气，成为有活力的城市目的地。

中文版 `index.html` 为主，英文版 `en.html`（线上 `/en`）由脚本生成，见下方「中英文两个版本」。

## 页面结构（2026-11-09 起按 Gehl 官网首页逻辑）

参照 gehlpeople.com 首页的顺序：一句使命 → 几段“我们做什么” → 精选项目 → 数字 → 客户 → 洞察 → 一句话收尾。KYWOO 为单页，Gehl 链到子页面的按钮改为跳到本页对应段落。

1. 首屏：全幅大照片轮播（有人气、聚拢人气的场所）＋口号「让冷清的空间，重新有人气。」，复用 `case-photos.js`（缓慢推近、交替、可点可滑可暂停）。照片在 `index.html` 的 `#top` 里按 `<img class="cp-slide">` 增减；目前为首尔路 7017（团队提供，`assets/hero/`）、朱家角古镇与杭州西湖边街景（Pexels）。选片原则：画面里有很多人在使用空间；优先 KYWOO 案例（杭州、朱家角）与团队成员过往项目，并确认有使用授权与摄影署名。
2. 我们做什么（2026-11-09 与方法合并为一屏）：3D 三角网络的三个节点就是三件事——数据·看见问题、空间·回应需要、活动·持续发生；点开节点看说明与具体问题，并分别跳到真实场地、服务、项目。
3. 项目：项目经验、城市更新参考、研究示例的卡片，每张标出涉及数据／空间／活动，可按方向筛选；点开看详细说明与照片来源（`projects.js`）。
4. 我们看的数：到访、停留、消费（代替 Gehl 的“数字”，不写未核实的数字）。
5. 三类空间：城市公共空间、城市商业空间、古镇文旅空间（代替客户 logo，不列客户名）。
6. 服务：读懂空间、选点轻改、品牌导视、活动与资源、测量复盘（取自朱家角研究汇报的“我们做五件事”），各标对应方向。
7. 如何一起工作：诊断、试点、复盘。
8. 研究与洞察：朱家角、武林银泰研究示例与城市→空间→决策导览。
9. 收尾：老空间，新人气。
10. 开始对话与常见问题；页脚分栏导航。

手机用点选；原生按钮支持键盘；暂停和系统减少动态关闭持续动画。WebGL不可用时保留静态三角、图片、说明与操作。案例内以同一个导览串联城市、空间与决策：城市画面使用真实地理资料，后两章为通用楼层与方法示范，不对应武林银泰实际建筑。桌面随滚动切换；手机和减少动态模式手动选章。查看地图或选择楼层时可暂停导览并返回。

## 中英文两个版本

- 中文 `index.html` 是主版本，所有内容先改这里。
- 英文 `en.html` 不要手改：在 `scripts/i18n_en.py` 里按「中文原句 → 英文」补一行，再运行 `python3 scripts/build-en.py` 生成。有中文没有对应英文时脚本会列出缺的句子并停止，不会写出半中半英的页面。
- 页头右上角 `EN` / `中文` 互相切换，页脚 Contact 栏也有入口；`<head>` 里用 hreflang 标出两个版本。
- 各脚本按 `<html lang>` 显示自己的界面文字（轮播按钮、筛选计数、地图说明、方法网络说明等）。

## 本地预览

```sh
python3 scripts/serve-preview.py
```

打开 http://127.0.0.1:5189/ 。预览服务器支持PMTiles所需的HTTP Range。运行脚本前在仓库根目录。

`app.js`、`scene.js` 管理首屏视频及通用楼层；`living-loop.js`、`living-loop-scene.js` 管理方法网络；`place-story.js` 管理真实地理地图与滚动导览。Three.js r170通过CDN按需加载，MapLibre与PMTiles运行库及许可保留在spatial/。

真实交互地图仍限定localhost预览；公开域名保留静态地理画面及来源说明。此限制尚未作为本次推送的一部分解除。
