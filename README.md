# KYWOO · Make Space Live

静态落地页，无构建步骤。定位：KYWOO 为既有城市公共空间、商业空间，以及古镇文旅空间提供循证的场所营造策略。我们融合数据、空间与活动的研究和洞察，让冷清的空间重新有人气，成为有活力的城市目的地。

中文版 `index.html` 为主，英文版 `en.html`（线上 `/en`）由脚本生成，见下方「中英文两个版本」。

## 页面结构（2026-11-09 晚起按 Gehl 首页的滚动方式）

页头：「项目」「服务」两项（鼠标移上去或键盘聚焦时展开小节）＋实底「联系我们」＋ EN／中文。页面自上而下：

1. 首屏：全幅大照片轮播＋主标题「让城市中失去人气的空间，重新充满活力！」＋定位句。向下滚动时照片缓慢下移放大、文字淡出（`scroll-fx.js`）。照片在 `#top` 里按 `<img class="cp-slide">` 增减。
2. 我们的原则（`#principles`，菜单「服务 › 关于我们」）：循证先行／从既有空间出发（含三类空间）／小步试点，持续复盘／数据 × 空间 × 活动。
3. 一句大字：「我们关心的，是人为什么来、在哪里停留、会不会再来。」随滚动逐字点亮（`scroll-fx.js`）。
4. 案例总览（`#cases`，菜单「项目」）：一行横向卡片，从左到右先是当前项目（朱家角、武林银泰，卡片照片自动轮换），再是过往经验（项目经验 4、JOA 建筑项目 5、城市更新参考 2）。可拖动、滑动、用箭头或「全部／当前项目／过往经验」切换；`#cases-current`、`#cases-past` 直接打开对应分组，`#project-xxx` 直接打开项目说明（`projects.js`）。
5. 数据化表达（`#approach`，菜单「服务 › 理论方法」）：数据 × 空间 × 活动 3D 三角。选一个方向，右侧列出对应方法，下方对应的方法卡亮起（`living-loop.js`）。
6. 六大方法策略（`#strategies`，菜单「服务 › 服务内容」）：01 场所研究与诊断、02 场所定位与商业策略、03 场所营造与轻量介入、04 内容策划与场所活化、05 成效评估与持续优化、06 城市、商业与文旅空间设计；每张卡用小三角与标签标出对应方向（数据：01 02 05；空间：01 03 06；活动：02 03 04）。
7. 数据化示范（`#data-demo`）：武林银泰城市 → 空间 → 决策导览（真实地理＋通用楼层）。
8. 我们看的数：到访、停留、消费。
9. 如何一起工作：诊断、试点、复盘。
10. 收尾：老空间，新人气。
11. 联系我们与常见问题；页脚分栏导航。

各段的标题与卡片进入画面时淡入上移（`.reveal`，可用 `style="--d:.08s"` 设延迟）；系统开启“减少动态效果”时，以上动效全部停止，大字直接完整显示。

手机用点选；原生按钮支持键盘；暂停和系统减少动态关闭持续动画。WebGL不可用时保留静态三角、图片、说明与操作。案例内以同一个导览串联城市、空间与决策：城市画面使用真实地理资料，后两章为通用楼层与方法示范，不对应武林银泰实际建筑。桌面随滚动切换；手机和减少动态模式手动选章。查看地图或选择楼层时可暂停导览并返回。

## 中英文两个版本

- 中文 `index.html` 是主版本，所有内容先改这里。
- 英文 `en.html` 不要手改：在 `scripts/i18n_en.py` 里按「中文原句 → 英文」补一行，再运行 `python3 scripts/build-en.py` 生成。有中文没有对应英文时脚本会列出缺的句子并停止，不会写出半中半英的页面。
- 页头右上角 `EN` / `中文` 互相切换，页脚 Contact 栏也有入口；`<head>` 里用 hreflang 标出两个版本。
- 各脚本按 `<html lang>` 显示自己的界面文字（轮播按钮、筛选计数、地图说明、方法网络说明等）。

## 本地预览

```sh
python3 scripts/serve-preview.py
```

打开 http://127.0.0.1:5189/ 。预览服务器支持PMTiles所需的HTTP Range。运行脚本前在仓库根目录。

`app.js`、`scene.js` 管理首屏视频及通用楼层；`living-loop.js`、`living-loop-scene.js` 管理方法网络；`place-story.js` 管理真实地理地图与滚动导览。Three.js r170通过CDN按需加载，MapLibre与PMTiles运行库及许可保留在spatial/。
